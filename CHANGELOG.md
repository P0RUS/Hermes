# 📜 Changelog

All notable changes to Hermes will be documented here.

---

## 🪽 v0.3 — The Oracle

### Added
- Feature importance analysis
- Experiment 001
- Evidence-based model interpretation

### Improved
- Better project documentation
- Release documentation structure

### Learned
- Course ID increased predictive performance but reduced interpretability.
- Engineering decisions should be validated through experiments rather than assumptions.

---

## 🌲 v0.2 — The Forest

### Added
- 5-fold cross-validation
- Fold-by-fold accuracy reporting

### Learned
- A single train/test split can be misleading.
- Cross-validation provides a more reliable estimate of model performance.

---

## 🪽 v0.1 — The Messenger

### Added
- Dataset exploration
- EDA
- Correlation analysis
- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- Multi-metric evaluation

### Learned
- Model selection should not rely on accuracy alone.
